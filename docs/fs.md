# 文件系统

## 目录相关
### 内置保留目录

```
root        根目录
├─bin       可执行文件目录
├─boot      系统启动文件
├─dev       硬件挂载目录
├─etc       配置中心
├─home      用户主目录
├─kernel    内核操作目录
├─opt       第三方应用可选目录
├─sbin      管理员可执行目录
├─tmp       缓存目录
├─user      用户目录
│  └─root   管理员用户目录
├─usr       Unix 系统资源
├─mnt       临时硬件挂载点
└─var       经常变化的数据
```
### permission.p权限文件
- 每个目录创建时会**自动生成**一个permission文件
- 该文件记录了**除了`kernel`用户外**每个用户可对当前目录做什么
- permission文件任何用户不可见**仅通过命令进行修改**
- 在用户创建目录时会**根据当前用户的模板文件进行填充permission**
- root有权限更改除`/kernel`外的任何目录的permission
- **默认情况下**`kernel`用户可无视所有的permission规则**如需禁用该配置请前往`/etc/kernel/config`目录（不推荐）**

### 目录命名规范
- 目录采用**UTF-8字符集**无法使用其他字符集的字符进行命名
- 目录名**不允许除了`@ # $ % &`外的符号**
- 目录名**不建议使用中文**可能会导致意想不到的结果
