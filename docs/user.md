# 用户系统

## 用户名规则

### 内置保留用户名
- `root`：非内核可访问**最高权限用户**
- `all`：代表当前系统**所有的用户**
- `kernel`：**用户态不可引用**`kernel`：任何来自用户态的系统调用都不能使用`kernel`作为用户标识（例如不能`su kernel`，不能将文件所有者设为`kernel`）。内核内部以`kernel`身份执行时，拥有所有权限，且绕过全部权限检查。这更符合“仅用于执行内核级事务”的定位。

### 其他规则
- 用户名仅可使用`A~Z a~z 0~9`的字符
- 用户名一旦创建**不可修改**
- 用户名全局唯一**不可重复创建**
- 用户名为对应用户**唯一标识**且不可修改

## 用户密码规则
- 用户密码仅支持使用`A~Z a~z 0~9 ! ? @ # $ % ^ & *`
- 用户密码必须包含数字与字母
- 密码长度必须在8~25位
- 不允许出现连续3位的连续数字如123、789等
- 使用`pwd <user>`用户密码修改时可与原密码相同但会提醒
- 修改密码时**非root用户**必须输入原密码

## 权限规则
- 默认情况下根据`/user/<name>/<name>.p`来管理mkdir创建的目录权限

### `<name>.p`权限模板文件默认内容

```p
[all]
path = 0b100
files = 0b1000

[root]
path = 0b111
files = 0b1111
files > permission.p = 0b1111

[<seif>]
path = 0b111
files = 0b1111
```

- `[all]`：all代表所有用户
- `path`：对应用户对该目录下目录内容的权限
- - `bit1`：对当前目录下的目录可见权限
- - `bit2`：对当前目录下的目录可访问权限
- - `bit3`：对当前目录下的目录可删除/创建项目权限
- `files`：对应用户对该目录下的文件内容的权限
- `files`：表示所有项目
- - `bit1`：对当前目录下的文件可见权限
- - `bit2`：对当前目录下的文件可读权限
- - `bit3`：对当前目录下的文件可写权限
- - `bit4`：对当前目录下的文件可执行权限
